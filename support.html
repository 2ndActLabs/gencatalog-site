GenCatalog Support and Setup Guide

A complete guide to importing, capturing, organizing, and browsing your AI-generated content across local files, ComfyUI, Grok Imagine, Arcana Labs, Gemini, GPT Image, Rogue Studio, Dzine, Higgsfield, Midjourney, Digen, and Venice.ai.
If Grok favorites are not loading, not showing, or saved images/videos disappeared, start with the recovery and backup links below.

Installation & Setup

Get GenCatalog running in a few minutes.

1
Download & Install the App

Mac: Download the DMG from gencatalog.app/get, open it, and drag GenCatalog to your Applications folder.

Windows: Download the installer (.exe) from gencatalog.app/get, run it, and follow the setup steps.

2
Choose Your Storage Folder

On first launch, GenCatalog asks you to select a folder where all media and metadata will be stored. Choose anywhere — an external drive works great for large collections.

3
Set Up Video Thumbnails (FFmpeg)

GenCatalog uses FFmpeg to generate video thumbnail previews. During setup, a prompt will appear — here's what to expect:

Mac: GenCatalog can install FFmpeg for you automatically. The process takes about a minute and requires no technical steps.

Windows: You'll be directed to a download page to grab the FFmpeg files you need. Follow the on-screen instructions to complete setup.

Image thumbnails work immediately without FFmpeg. This step only affects video previews.

4
Install the Chrome Extension

Install the GenCatalog extension from the Chrome Web Store. Works in any Chrome-based browser (Chrome, Brave, Edge, Arc, and more).

5
Start Saving

GenCatalog lives in your menu bar (Mac) or system tray (Windows). As long as it's running, the extension is active and ready across all supported platforms.

Tip: Set GenCatalog to launch at login so it's always ready — Mac: System Settings → General → Login Items. Windows: Settings → Apps → Startup.

Open a Supported Generator

Use the desktop app's Go menu to open Grok Imagine, Midjourney, Higgsfield AI, Digen AI, Venice AI, GPT Image, Gemini, Rogue Studio, Arcana Labs, or Dzine. Open in Browser opens your local catalog instead.

System Requirements

  • macOS 10.15 (Catalina) or later
  • Apple Silicon (M1/M2/M3/M4) or Intel Mac
  • Any Chrome-based browser (Chrome, Brave, Edge, Arc, and more)
  • Windows 10+ (x64) — download here

The Chrome Extension

The bridge between AI platforms and your local catalog.

Click the GenCatalog icon in your browser toolbar to open the popup. It now centers the status and controls that matter for the platform you're on:

  • Connection state — if the desktop app is open, the popup connects automatically; if not, open the app and wait a few seconds
  • Trial or license state — the chip and banner explain whether you're licensed, in trial, offline, or at a save limit
  • Active platform controls — Grok, Arcana Labs, Gemini, GPT Image, Rogue Studio, Dzine, Midjourney, Higgsfield, Digen, and Venice each show the controls that apply to that site
  • Recent saves — your latest captured items and save confirmations
  • Open Catalog / Settings — launch your catalog or manage persistent download preferences
Download options: Smart Sync lives in Settings and stays remembered after you set it once. Grok video upscaling is handled from the desktop catalog, not from the extension scan flow.
If the popup cannot connect: Open the GenCatalog desktop app, wait a few seconds, then try again.

Local Media Import

Bring downloaded images and videos into GenCatalog even when they did not come from the browser extension.

Use local import for ComfyUI output folders, API-generated videos, files you saved manually, old downloads, exported images, screen recordings, or media from a generator GenCatalog does not capture yet. GenCatalog copies those files into your selected catalog folder so they live beside the rest of your library.

How to Import Files

1
Open the GenCatalog desktop app

Local import uses the desktop app because it needs permission to read files from your Mac or PC.

2
Choose files or drag them in

Click Import in the toolbar, use the import card in Settings → Capture & Import, or drag supported files onto the GenCatalog window.

3
Review the batch

After import, use the review drawer to set source, model, tags, prompts, and notes. For ComfyUI files with embedded metadata, GenCatalog can automatically fill in source, prompt, checkpoint, settings, and LoRA details.

ComfyUI Metadata Import

When imported files include embedded ComfyUI prompt or workflow metadata, GenCatalog labels the item as ComfyUI and surfaces the workflow context in the item detail view.

  • Prompt and workflow: positive and negative prompt text when present, plus the saved workflow metadata.
  • Generation settings: checkpoint/model, seed, steps, CFG, sampler, scheduler, denoise, dimensions, and related settings when available.
  • LoRAs: LoRA names plus strength, model strength, and clip strength values when the workflow includes them.
  • Search behavior: ComfyUI remains the source/tool, while the checkpoint is searchable as the model.

If a file has no embedded ComfyUI metadata, it still imports as a normal local file that you can tag, rate, annotate, and search.

Supported File Types

  • Videos: MP4, MOV, WEBM, and M4V
  • Images: JPG, JPEG, PNG, WEBP, GIF, and AVIF

Duplicates and Undo

GenCatalog checks exact file hashes during import. If the same file is already in your catalog, it is skipped by default. You can still choose Import anyway from the review drawer when you intentionally want another copy.

If you import the wrong batch, click Undo from the import toast. GenCatalog removes the just-imported items and their copied files from the catalog.

Tip: For xAI/Grok API videos, download the file before leaving the console page, then import it into GenCatalog. The imported copy stays in your local library and can be tagged or labeled like any other saved generation.

Grok Imagine

Full support for saving images and videos — individually or in bulk from your favorites.

✓ grok.com  ·  x.com/i/grok

Saving Individual Generations

When viewing any Grok Imagine generation, a blue GenCatalog save button (⊞ grid icon) appears on the media. Click it to save instantly. The button shows a spinner while saving, a green checkmark on success, or orange if it's already in your catalog.

Tip: Saving from a detail page captures the most complete metadata including the full prompt. Grid view saves also work but may capture less metadata.

Choose What You Want to Import

On Grok, open the GenCatalog extension, then Settings → Download options → Grok source. Choose the source that matches how you create:

  • Imagine and Agent Mode creations: choose Grok Image + Agent Mode. This checks Grok's generated-media library without scanning the chat-media feed.
  • Regular chat creations: choose Chat boxes only. This checks the chat media Grok makes available, rather than the Imagine and Agent Mode library.
  • A mix of both: choose All Grok media for the broadest available scan.

What about projects? A project is a place to organize conversations, not a separate import choice. An image created in an ordinary project chat is still chat media; placing it in a project does not make it an Imagine or Agent Mode creation.

These choices control bulk scans, not individual save buttons. The selection is remembered. After changing it, run a new scan. Changing the source does not remove anything already saved in your catalog.

Project-chat filtering update: Extension 5.140 has been submitted to the Chrome Web Store and is awaiting publication confirmation. It improves filtering of ordinary chat images that Grok also lists in its generated-media library. Source separation depends on the information Grok provides; some items may still be included when their origin cannot be determined.

Bulk Downloading Your Favorites

1
Open the extension popup on grok.com

Keep the GenCatalog desktop app running, sign into the Grok account you want to scan, and choose your Grok source in the extension Settings.

2
Click the Grok tab → "Scan Favorites"

GenCatalog checks the selected Grok sources and compares the results with your catalog. Review the counts for already saved items, new items, and previously deleted items before downloading.

3
Click "Download N new items"

Downloads only items not already in your catalog. Progress strip shows real-time status as the batch runs.

4
Pause & Resume anytime

Pause a bulk download and resume it later. Progress is preserved — already-saved items won't be re-downloaded.

Check for Missing Items in This Account

Use Settings → Check this Grok account when you want GenCatalog to check for missing media in the account currently signed into Grok and download it into your catalog. This is a separate action from the regular Scan Favorites → Download flow; both use your selected Grok source.

Existing files and intentional exclusions are preserved. Keep GenCatalog and the Grok tab open, and stay signed into the same account until the check finishes. You can close the extension popup.

Older and Removed Media

Leave Settings → Include older and removed items off for normal imports. Turn it on when you want to try retrieving older versions or items Grok marks as removed. GenCatalog can only download files Grok still makes accessible; permanently deleted files cannot be recovered.

This option does not override items you intentionally excluded through GenCatalog, and it does not clean up previously imported items. Review unwanted catalog items individually; do not delete from Grok just to change what your next scan imports.

Multiple Grok Accounts

GenCatalog supports saving from multiple Grok accounts into a single catalog. Each item is automatically tagged with the account it came from, so you can filter your catalog by account. Finish the current account's scan or check before switching accounts. Then sign into the next account, confirm your Grok source selection, and scan or check that account separately.

Keeping Original Grok Reference Images Local

Grok may expose an uploaded or source image through an account-protected online link. GenCatalog uses that exact image when it can and can store an exact local copy beside your catalog. It does not substitute a generated result or extract a frame from a derived video.

1
Open References in the desktop catalog

Set Service to Grok, Copy to Online only, and Account to one historical Grok username. The repair count updates to that account's remaining online references.

2
Open the matching Grok account in Chrome

Open grok.com, sign in to the same account you selected in GenCatalog, and leave that tab open. The repair waits instead of using a different signed-in account.

3
Start the account's repair

Click Repair references in the Grok maintenance panel. You may close the References window while it works; keep GenCatalog and the matching Grok tab open. You can pause, resume, or cancel without losing completed work.

4
Repeat for other accounts

If your catalog includes more than one Grok account, select each account and run the repair again while Chrome is signed into that same account.

  • Stored locally — GenCatalog saved the exact reference image into your local catalog.
  • Unavailable on Grok — Grok reports that the original link no longer exists.
  • Could not be fetched — the account, sign-in, network, or Grok response prevented a download. Confirm the matching account in Chrome and run that account again.
Another way in: Open Settings → Maintenance → Repair Grok references, then click Review references. This opens the same account-filtered References workflow.

Upscaling Grok Imagine Videos

Grok video upscaling is available from the GenCatalog desktop app so you can choose exactly which saved videos to change. The Chrome extension does not bulk-upscale videos during scan or download.

1
Open the video in your desktop catalog

Click a saved Grok Imagine video to open its detail view. If the video can be upgraded, the Upgrade row appears below the Grok link.

2
Choose the next quality level

Select the available target, such as 720p or 1080p, then click Upgrade. GenCatalog queues the upgrade and updates the local file when Grok returns the upgraded version.

3
Use the right Grok account

Keep grok.com open in Chrome using the account or Chrome profile that created the video. If you use multiple Grok accounts, switch to the saved item's source account before retrying an upgrade.

You can also select multiple Grok videos in the desktop app, then use the selected-item Upgrade action to queue those chosen videos. For large libraries, review a small group first so you are confident the upgraded versions are the ones you want to keep.

Smart Sync & Exclusion

When you delete an item through GenCatalog, it's added to a permanent exclusion list and will never be re-downloaded during future bulk scans — even if it's still in your Grok favorites.

Always delete through GenCatalog — not by removing files in Finder. Only GenCatalog-deleted items are added to the exclusion list.

Saving New Generations

Open Arcana Labs in Chrome with GenCatalog running. As your own generations complete, the extension captures Arcana's generation media and joins it with the matching prompt metadata when Arcana exposes it through the app.

Backfilling History

When you are signed into Arcana, open the GenCatalog extension popup on app.arcanalabs.ai and choose Backfill History. GenCatalog imports your account generations and skips community or showcase media that does not belong to your library.

What Gets Saved

GPT Image

Bulk download ChatGPT Images into your local catalog at full resolution, with recovered prompts attached when ChatGPT still exposes them.

✓ chatgpt.com  ·  chat.openai.com

Quick Start

1
Open ChatGPT Images

Sign in to ChatGPT and open your image library. Scroll the grid to load the images you want GenCatalog to see.

2
Click Scan in the GenCatalog extension

GenCatalog finds loaded ChatGPT Images, compares them with your local catalog, and recovers prompts for a small batch of the newest promptless images.

3
Download Ready images

When images are marked Ready, click Download to save the full-resolution files with their recovered prompts.

4
Backfill older prompts

If images are Held, click Backfill prompts. Backfill works in batches and resumes from the progress already made.

What the Counts Mean

  • Found — generated images GenCatalog can currently see in the loaded ChatGPT Images grid.
  • Saved — found images already present in your GenCatalog catalog.
  • Ready — new images with a recovered prompt, ready to download.
  • Held — found images whose prompt has not been recovered yet.

Held does not mean failed. It means GenCatalog found the image, but is still waiting to recover the prompt that belongs with it.

Why Prompts Take Longer Than Images

Finding images is fast because ChatGPT keeps an image library. Recovering prompts is slower because the prompt usually lives back in the original conversation where the image was created.

GenCatalog reads those conversations in small batches so Scan stays quick and Backfill can stop cleanly when ChatGPT starts limiting prompt lookups.

Backfill Prompts

Use Backfill prompts when you have older held images. Each run recovers as many prompts as ChatGPT currently allows, reports what changed, then stops. If ChatGPT rate limits the lookup, wait a few minutes and run Backfill again.

You do not need to wait for every held image to recover before downloading. Whenever images become Ready, you can download that ready set.

Why Some Images Stay Held

A small number of images may never get a recoverable prompt. The original conversation may have been deleted, the image may have come from a short photo-edit instruction, or the recoverable prompt may be only a brief follow-up such as "make it warmer."

GenCatalog does not invent missing prompts, and it intentionally leaves Held images out of download so your catalog stays searchable and useful.

Tip: Prompt recovery works best after a break or at the start of a session. Running Backfill repeatedly in quick succession may recover fewer prompts because ChatGPT has not refreshed the available lookup allowance yet.

Gemini

Scan Gemini Library or save visible chat generations with their original prompts and Gemini's full-size image.

✓ Gemini Library scan + individual saves

Scanning Gemini Library

Open gemini.google.com/library, wait for your images to load, then open the GenCatalog extension and click Scan. GenCatalog compares the Library with your local catalog and reports what is already Saved, New, previously Deleted, Ready to download, or Held for a prompt.

Scan recovers a small recent set of prompts automatically. Prompt-matched images become Ready without waiting for the rest of the Library.

Recovering Older Prompts

When older images remain Held, click Backfill prompts. Each run retrieves another careful batch of original prompts from the conversations that created those images and updates matching saved items that are missing prompt context.

You can download the Ready set at any time. Images still missing a trustworthy prompt remain Held so incomplete records do not enter your catalog.

Downloading New Images

Click Download N new to save the prompt-matched set. GenCatalog uses Gemini's own full-size download for each image, moves the completed file into your catalog, and removes the temporary copy from Downloads.

If Gemini's full-size download cannot complete, GenCatalog leaves the image unsaved rather than substituting a lower-resolution preview.

Saving from a Conversation

Open a Gemini conversation and click the GenCatalog save badge on a generated image to save it individually. In multi-turn chats, each generated image stays connected to the nearest prompt that created it. Uploaded images, previews, and Gemini templates are not treated as generated outputs.

What Gets Saved

  • Gemini's full-size image file
  • The original prompt recovered for that specific response
  • The source conversation link and stable Gemini identity
  • Creation time and available generation context

Current Limits

  • Gemini support currently covers image generations, not Gemini video.
  • Library Scan works with the records Gemini currently makes available. Load more Library items and scan again when older work is not yet listed.
  • Gemini may temporarily limit prompt lookups. Wait a few minutes before running Backfill prompts again.
  • Images whose source conversation or prompt is no longer available may remain Held.
  • Saved Gemini items stay local in GenCatalog, just like your other catalog media.

Dzine

Scan generated images and videos across all of your Dzine projects, then import new results in bulk.

✓ dzine.ai  ·  images and videos

Scan All Projects

1
Open Dzine in Chrome

Go to dzine.ai, sign in, and leave the Dzine tab open. Make sure the GenCatalog desktop app is running.

2
Open the extension and select Dzine

The popup should show Connected · Dzine and the Dzine platform card.

3
Click "Scan All Projects"

GenCatalog walks your Dzine project history and compares each generated output with your local catalog. The popup reports Found, Saved, New, and Held counts.

4
Click "Download New"

Only new generated images and videos are imported. Work already saved or previously deleted stays skipped.

Large libraries: Dzine scans keep a local resumable checkpoint. If Chrome closes or the scan is interrupted, reopen the signed-in Dzine tab and run the scan again to continue safely.

What Gets Saved

  • The generated image or video file
  • Prompt and negative prompt when Dzine makes them available
  • Full model name, style, seed, dimensions, aspect ratio, quality, and creation time
  • Project and canvas context plus supported image and video controls
  • Source and reference media as creative context, not as generated results

Found, Saved, New, and Held

  • Found — generated outputs discovered across your Dzine projects
  • Saved — outputs already present in GenCatalog
  • New — outputs ready to import
  • Held — outputs waiting for prompt or detail metadata, or an unsupported result type that GenCatalog will not mislabel

Run Scan All Projects again later to retry Held items after Dzine exposes the missing details.

Repair Older Dzine Model Names

If an earlier Dzine import shows a numeric model ID instead of a name, open Settings → Maintenance in the desktop app and run Repair Dzine model names. The repair is limited to Dzine items and uses the model details already preserved in their metadata.

Higgsfield

✓ higgsfield.ai

Where Save Buttons Appear

  • Grid / browse pages — a save badge appears on each thumbnail in your library, explore feed, and profile
  • Modals / lightboxes — save button appears automatically when you open any generation in a lightbox

Bulk Saving Your Library

1
Scroll through your Higgsfield library

Browse your personal library or any grid page. GenCatalog caches items as they appear on screen.

2
Open extension → Higgsfield tab → "Scan Library"

Use this the first time to read the current cache and initialize the Higgsfield counts.

3
Scroll more, then click "Refresh Count" and "Sync New"

Captured Metadata

Venice.ai

Privacy Tools

GenCatalog's first privacy tools help keep your local library covered when someone else can see or use your computer.

What App Lock Does

App Lock requires confirmation before opening GenCatalog. On supported Macs, you can unlock with Touch ID or your App Lock password. On Windows, App Lock uses your App Lock password.

App Lock is designed for everyday desktop privacy: stepping away from your computer, sharing a workspace, or keeping your local catalog from opening casually.

Turn On App Lock

  1. Open GenCatalog.
  2. Go to Settings → Privacy.
  3. Turn on App Lock.
  4. Create and confirm your App Lock password.
  5. On supported Macs, enable Touch ID unlock if you want biometric unlock.
  6. Choose when GenCatalog should lock, such as on launch, idle, sleep, or manual lock.
Tip: Once App Lock is configured, GenCatalog asks for confirmation before opening Privacy settings or turning Privacy Mode off.

What Privacy Mode Does

Privacy Mode gives you a safer way to browse, demo, or screen-share your catalog. It blurs sensitive previews and keeps videos muted while protection is on, so clicking a blurred video does not unexpectedly play audio.

You can turn Privacy Mode on from the app's Privacy controls. Turning it off requires App Lock confirmation when App Lock is enabled.

Important Security Boundary

App Lock, Privacy Mode, and Hidden Items protect against casual viewing inside the app. They do not encrypt normal library files on disk. For encrypted storage, move selected generations into Private Vault.

Private Vault

Private Vault is encrypted storage for generations that need stronger protection than hiding, blurring, or locking the app window.

What Private Vault Does

Private Vault creates a separate encrypted area inside your GenCatalog library. When you move an item into the Vault, GenCatalog encrypts that item's media file, thumbnail, prompt, and metadata, then removes the normal plaintext library copies.

While the Vault is locked, GenCatalog does not show Vault contents, counts, names, thumbnails, prompts, or metadata. Unlock the Vault when you need to view those items or move them back to your normal library.

What "Encryption at Rest" Means

Encryption at rest means the Vault data is stored in encrypted form while it is sitting on your drive. If someone browses your catalog folder in Finder or File Explorer while the Vault is locked, the Vault media and metadata should not be readable without unlocking the Vault in GenCatalog.

This is different from App Lock or Privacy Mode. App Lock controls access to the GenCatalog window. Privacy Mode blurs content on screen. Hidden Items keeps items out of the main grid. Private Vault is the feature that encrypts selected items on disk.

Set Up and Unlock

  1. Open GenCatalog.
  2. Click Private Vault in the sidebar.
  3. Create a Vault password.
  4. Save the recovery key somewhere safe.
  5. On supported Macs, enable Touch ID if you want faster day-to-day unlocks.
Recovery note: Keep your Vault password and recovery key safe. If both are lost, encrypted Vault contents cannot be recovered.

Move Items In or Out

Use Move to Vault on a library item or selected group of items. To restore an item to the normal library, unlock the Vault and choose Move to Library. Moving an item out decrypts it and restores it as a regular, unencrypted library item.

Hidden Items

Keep private generations out of the main grid without deleting them.

Hidden Items removes selected content from your main catalog view. Nothing is deleted — your files, prompts, and metadata are preserved, and hidden content can be restored later.

Hiding Items

Open any item in the detail view and click Hide. The item disappears from the main grid immediately and moves to your hidden collection.

Accessing Hidden Items

Click Hidden Items in the sidebar. If App Lock is enabled, GenCatalog asks for the same App Lock confirmation used for the rest of your privacy controls. On supported Macs, that can be Touch ID; on Windows, it is your App Lock password.

If you have not enabled App Lock, Hidden Items can still use the older Hidden Items PIN flow. Once verified, hidden items appear in a separate grid view with the same browsing, search, and filter capabilities as the main catalog.

Restoring Hidden Items

While in the hidden view, hover over any item and click Unhide. The item returns to your main catalog.

Changing Hidden Access

For the simplest setup, turn on App Lock in Settings → Privacy and use that unlock flow for Hidden Items. If App Lock is not enabled, go to the sidebar → Hidden Items → Change PIN to manage the fallback PIN.

Security note: Hidden Items is a privacy feature for the app interface. It is not encrypted storage. For stronger at-rest protection inside GenCatalog, move selected items into Private Vault.

Trash & Deletion

Deleting an item moves it to Trash first — nothing is immediately gone.

Managing Trash

  • Click View Trash in the sidebar to see deleted items with deletion dates
  • Restore any individual item using the button on each row
  • Restore All — one-click button to recover everything in trash at once
  • Multi-select — click items to select them, then use the floating action bar to Restore Selected or Delete Permanently
  • Empty Trash to permanently delete all trashed items
Always delete through GenCatalog — not via Finder. Finder deletions break the catalog database and don't add items to the exclusion list, meaning they may reappear in future scans.

Exclusion List

Every item deleted through GenCatalog is permanently added to an exclusion list. It will never be re-downloaded during future bulk scans — even if it still exists in your Grok favorites.

Mobile Access

On Your Home Network

Your catalog is accessible from any device on your Wi-Fi. GenCatalog shows a QR code in the catalog sidebar — scan it with your phone to open your catalog instantly. Or type your Mac's local IP (shown in the sidebar) into your phone's browser followed by :8080.

From Anywhere

Install Tailscale (free) on both your Mac and phone. Once set up, you can access your full catalog from anywhere in the world — coffee shop, travel, anywhere — as long as your Mac is on and running GenCatalog.

Note: Your Mac needs to stay awake for remote access. Consider disabling sleep in System Settings → Battery.

Subscription & Activation

After subscribing, you'll receive a license key by email. Open Settings → License, choose Already subscribed? Enter key, paste the key, and select Activate. Initial activation requires internet.

A new annual subscription is for one individual and can be used on up to three devices they personally control. If a replacement computer unexpectedly reaches the limit, email support@gencatalog.app with your order number.

Subscription states

  • Active: new capture and imports are ready, and your paid-through date appears in Settings → License.
  • Canceled, still paid through: everything keeps working until the date shown. Canceling does not end access early.
  • Subscription ended: everything already in your library remains fully usable; new capture, imports, scans, and other ways of adding new work pause.
  • Renewed: open Settings → License, select Renew to keep capturing, and verify the renewed key. New acquisition returns without changing your library.
  • Perpetual: customers who purchased before the subscription transition keep the perpetual access and update rights included with their original purchase. No subscription is required.

If verification is unavailable

A short verification outage does not immediately interrupt a current subscription. If GenCatalog cannot verify for longer, an already-paid customer falls back to library management—not a lockout. Browse, search, tag, organize, compare, export, back up, and restore remain available while new capture and imports wait for verification.

Current desktop and extension releases remain available to legitimate paid customers, including customers whose subscriptions have ended.
