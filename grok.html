Creative ownership

History is what a platform lets you see. An archive is what you actually own.

I built GenCatalog after realizing that almost everything I had made in Grok existed only because Grok still chose to host it.

Interfaces change. Features move. Policies tighten and relax. The recent moderation changes are one more reminder that a platform and its boundaries can change long before your ideas do. That does not make Grok uniquely bad. It makes Grok a platform—and hosted history isn’t an archive.

Preserve

Save the generation. Keep the reason it mattered.

Use the save controls inside Grok as you work, or bring an existing library across in bulk. GenCatalog keeps the media and the available creative context together instead of leaving you with an anonymous download.

  • One-click capture: save an image or video, with the option to favorite it locally at the same time.
  • Bulk library capture: scan existing Grok media, skip duplicates, and continue long jobs in the background.
  • Smart Sync: recognize what is already saved and focus on what is new.
  • Prompt safeguards: hold generated work when a prompt should be recoverable instead of silently filing an incomplete record.

Understand

Every reference can become the root of a family tree.

A result is more useful when you can see where it came from. GenCatalog preserves source relationships so you can move through the images, edits, variations, and videos that grew from the same reference.

  • Reference lineage: browse the creative descendants of a source image instead of hunting for them one by one.
  • Exact reference copies: store the original local reference when Grok still makes it retrievable.
  • Historical repair: repair missing references account by account, with pause, resume, cancel, and clear status.
  • Generation Recipes: keep image prompts and motion prompts distinct across multi-stage work.
Find

The generation you forgot is often the one worth finding.

Search prompt text, accounts, sources, models, filenames, notes, and tags from one field. Then narrow the result without losing your place—or let Rediscover surface work you had stopped thinking about.

  • Universal search: prompt, tag, model, source, account, filename, and notes.
  • Deep filters: media type, date, rating, favorite, notes, prompt, reference, tags, and upgradeability.

Multiple accounts

One library. Every Grok identity still intact.

Creators rarely stay inside one account forever. GenCatalog can place work from multiple Grok accounts in the same catalog without flattening away where it came from.

  • Automatic account labels: record the source account when Grok exposes it.
  • Composable filters: combine an account with source, media, tag, rating, date, prompt, or any other filter.
  • Account counts: understand how the library is distributed at a glance.
  • Correct-account workflows: repair references and request upgrades from the Grok identity that owns the work.
Repair

Keep the original references, not just the generations they produced.

GenCatalog shows which source images are already local, still online, or missing—and lets you work through historical Grok reference recovery in the account that owns them.

  • Reference inventory: search and sort sources by service, account, copy state, first use, and number of descendants.
  • Account-scoped repair: select one Grok account, open a matching signed-in tab, and recover what remains available.
  • Durable background jobs: pause, resume, or cancel without making the popup own the work.
  • Clear outcomes: distinguish a local source copy from an online-only or missing reference.
Reuse

Turn a finished image back into a working idea.

Recipe View reconstructs the creative trail behind a generation. Copy the prompt, study the stages, export the recipe, compare two approaches, or return to the original Grok record when its source link is available.

  • Recipe Cards: export a visual record that keeps the result and the prompt together.
  • PNG + JSON export: share the human-readable idea or preserve the structured recipe.
  • Recipe Compare: place two generations and prompts side by side to see what changed.
  • Original source links: open a saved item back in Grok when the link is available.

Shown in the current Recipe View with an illustrative source preview. More complex Grok lineages add the additional stages GenCatalog can recover from the source.

Upgrade

Upgrade Grok videos without leaving your library.

Find videos that Grok can upgrade and manage the work as a queue from inside GenCatalog. GenCatalog supports 720p upgrades; 1080p upgrades require a Grok Heavy subscription. Quality badges make the final state visible without opening every file.

  • Upgradeable video filter: isolate the work that is eligible.
  • Individual or bulk queue: upgrade one video or work through many.
  • Quality badges: see the stored resolution at a glance.
  • Account-aware guidance: get pointed to the correct Grok account when an upgrade needs it.
  • Original timeline preserved: the upgraded file stays anchored to when the work was first created.

Upgrade availability depends on what Grok supports for the source video and signed-in account. 1080p requires an active Grok Heavy subscription.

Before you start

A few honest answers.

Why not leave my work in Grok history?

Grok history is useful. It is also a hosted interface controlled by a platform. Your own archive keeps local copies of the media and available creative context so you can search and use the library independently—even while you continue creating in Grok.

Can GenCatalog save an existing Grok Imagine library?

Yes. GenCatalog can scan and save existing Grok media in bulk, recognize items already in your catalog, and resume long-running work. You can choose broad or narrower Grok capture scopes. Source availability still depends on what Grok exposes to the signed-in account.

Does it support more than one Grok account?

Yes. When Grok exposes account identity, GenCatalog records it so work from multiple accounts can live in one catalog and still be searched, filtered, repaired, and upgraded in the correct account context.

What stays local?

Your saved media, prompts, metadata, tags, notes, ratings, collections, and other library records live in the catalog folder you choose. GenCatalog runs on Mac and Windows and supports catalogs on external drives.

Can GenCatalog recover media that is already gone?

No. GenCatalog can preserve and organize media that Grok still makes available, and it can repair some missing prompts and references while they remain retrievable. It cannot recreate source media that was never saved and is no longer available. The best time to build an archive is while the source still exists.

Is GenCatalog affiliated with xAI?

No. GenCatalog is an independent product and is not affiliated with or endorsed by xAI.
